# LazyFS website

A single-page, dependency-free website for [LazyFS](https://github.com/dsrhaslab/lazyfs):
plain HTML, CSS and a little JavaScript. No dependencies, no `node_modules`: just one small Python script that assembles the page.

```
index.html   the page: generated by build.py, not in git (don't edit it)
src/
  layout.html      <head>, menu bar and footer
  sections/        one file per section, in page order (01-hero.html … 08-paper.html)
build.py     joins src/ into index.html
style.css    styles (light/dark follow the system setting)
app.js       animated "pull the plug" demo, bugs list, fault toggle, copy buttons
data/        community.json: "Used by & written about" logos and references
assets/      logo, sloth icon, favicon, adopter logos
```

## Edit content

- **Bugs list**: `BUGS` array in `app.js`.
- **People**: the Team list is in `src/sections/09-people.html` (name, GitHub user and an optional tag: Author, Maintainer, Jepsen).
  Contributors are not edited by hand: the page loads them from the GitHub API when it opens.
- **Used by & written about**: `data/community.json`. It has two lists:
  - `adopters`: the logo row. Each entry: `name`, `note`, `logo` (a file in `assets/logos/`), `url`.
  - `references`: the cards. Each entry: `title`, `kind` (e.g. `Jepsen report`, `Blog`, `Integration`),
    `date` (`YYYY-MM`), `text`, `url`. Order doesn't matter: cards are sorted newest first.

  To add one, copy an entry and change it; to remove one, delete it (mind the commas, it must stay valid JSON).
  The page loads this file over HTTP, so open the site through a server (see below), not by double-clicking `index.html`.
- **Everything else**: the matching file in `src/sections/` (or `src/layout.html` for the menu and footer).
  Then run `python3 build.py` to regenerate `index.html` (it is in `.gitignore`: only `src/` is committed).
  To add a section, create a new file in `src/sections/`; its number sets its place on the page.

## Google Analytics

The site uses Google Analytics 4, loaded **only after the visitor accepts** a small banner
(GDPR: analytics cookies need consent). The choice is kept in `localStorage` and can be changed
from the *Analytics settings* link in the footer, which also says the site uses Google Analytics.

- The ID is in `src/layout.html`: `<meta name="ga-id" content="GTM-PSZJGCQM">`. It can be a
  Tag Manager container (`GTM-…`, GA configured inside GTM) or a GA4 Measurement ID (`G-…`).
- While it is the placeholder `G-XXXXXXXXXX`, nothing is loaded and the banner and footer note are hidden.
- The logic is at the end of `app.js`.

## Run locally

Build the page, then serve the folder with any static file server:

```bash
python3 build.py
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deploy to GitHub Pages

Automatic: every push to `main` runs `.github/workflows/deploy.yml`, which runs `build.py` and publishes
`index.html`, `style.css`, `app.js`, `assets/` and `data/` (not `src/` or `build.py`).
It can also be started by hand in the *Actions* tab (*Deploy to GitHub Pages → Run workflow*).

One-time setup: *Settings → Pages → Build and deployment → Source: GitHub Actions*.
All paths are relative, so the site works under any base path (e.g. `/lazyfs-web/`).
