# #1 - PostgreSQL


**Description:**
A PostgreSQL user reports a corruption of the statistics file (pgstat.stat) after restoring the database from a cold backup. The development team suggests this corruption can result from a partially written statistics file in the backup.

- **Type of fault**: Lost write
- **Impact**: Data Corruption/Loss
- **Error**: Corrupted File
- **Date**: 2012
