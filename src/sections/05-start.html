Get started

Linux with FUSE 3. Tested on Debian 11 and Ubuntu 20.04 over ext4.

1 · Build
sudo apt install g++ cmake libfuse3-dev libfuse3-3 fuse3
echo "user_allow_other" | sudo tee -a /etc/fuse.conf
git clone https://github.com/dsrhaslab/lazyfs.git && cd lazyfs
cd libs/libpcache && ./build.sh && cd -
cd lazyfs && ./build.sh
2 · Mount
mkdir -p /tmp/lazyfs.mnt /tmp/lazyfs.root
./scripts/mount-lazyfs.sh -c config/default.toml \
    -m /tmp/lazyfs.mnt -r /tmp/lazyfs.root -f
3 · Break things
# what would be lost right now?
echo "lazyfs::unsynced-data-report" > /tmp/faults.fifo
# power failure: drop everything not fsynced
echo "lazyfs::clear-cache" > /tmp/faults.fifo
# crash right before an fsync to any file matching "wal"
echo "lazyfs::crash::timing=before::op=fsync::from_rgx=wal" > /tmp/faults.fifo

Precise faults (torn-seq, torn-op, clear) can also be declared in the TOML config: see Supported faults. Full reference in the README.
