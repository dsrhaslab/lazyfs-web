How it works

LazyFS is a FUSE file system that sits between your system and a regular file system (e.g., ext4). Your system runs unmodified: just point its data directory to the LazyFS mount point. Inside LazyFS, three components decide what reaches the disk.

  • Writes stay in the LazyFS cache. Reads are served from it, so your system always sees its own data.
  • Data reaches ext4 only on fsync/fdatasync, or when a torn-write fault persists part of it on purpose.
  • A fault decides the rest. Whatever is still in the cache when a fault fires is gone, exactly what a power cut would lose.
  • You see what was lost. Before each fault, LazyFS logs which blocks were never persisted, so every bug comes with an explanation.
